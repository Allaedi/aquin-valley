# AQUIN Valley

A small browser-based narrative driving game inspired by the supplied AQUIN Valley concept. Explore a winding alpine road, visit the Aquin fuel stop, collect six records about the Millfold flood, and carry the evidence to the northern pass.

## Play

Open `index.html` in a modern browser with WebGL and an internet connection (Three.js and optional fonts load from CDNs). On GitHub Pages, publish the repository root to play it as a static site.

## Controls

- **WASD** or **arrow keys** — drive and steer
- **Shift** — temporary boost
- **E** — investigate nearby evidence or talk to Odile
- **Tab** — review the evidence dossier
- **L** — headlights
- **T** — day/dusk
- **R** — recover to the road
- **Esc** — pause

Progress is stored locally in the browser. Use **New journey** on the epilogue screen to clear the local save.
